## Open Profile or sign out

Look near the bottom of the menu. On a phone, tap **Open navigation** first.

![The bottom of the menu with Profile and Sign out highlighted.](/learn/settings/settings-menu.png "Finding Profile and Sign out")

1. Select **Profile** to open your profile and password options.
2. Select **Sign out** when you want to end your session.

## Edit your profile

![The profile form with four numbered highlights and a read-only email field.](/learn/settings/profile.png "Your profile settings")

1. Edit **Name** to change the name Budget Together uses for you.
2. Enter a valid **Time zone**, such as `America/Boise`. This changes your profile only. Budgets you already have keep the reporting time zone they started with.
3. Select **Save profile** to save your name and profile time zone.
4. Select **Change password** to open the password form.

You can see your sign-in address in the read-only **Email** field.

## Change your password

In **Profile**, select **Change password**.

![The change password dialog with both password fields and Save password highlighted.](/learn/settings/change-password.png "Changing a password while signed in")

1. Enter your **Current password**.
2. Enter a **New password** with at least 12 characters.
3. Select **Save password**. This signs you out of your other sessions.

## Reset a forgotten password

![The sign-in form with Forgot password highlighted.](/learn/settings/sign-in.png "Starting on the sign-in screen")

1. Select **Forgot password?**.

![The reset request form with Email and Send reset link highlighted.](/learn/settings/request-reset.png "Requesting a reset link")

1. Enter the **Email** you use to sign in.
2. Select **Send reset link**. Budget Together sends a link if the address has an account.

Open the reset email and select **Reset password**.

![The new password form with Password and Save password highlighted.](/learn/settings/choose-new-password.png "Choosing a new password from a reset link")

1. Enter a **Password** with at least 12 characters.
2. Select **Save password**. Sign in with your new password when the sign-in screen returns.

If your link expired or you already used it, request a new one from **Forgot password?**.
